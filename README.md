Proyek Tumbal
## Isi

- `scraper/` — kode Python buat ambil dan parse data
- `docs/` — web statis + JSON, yang tayang di Pages
- `.github/workflows/` — penjadwalan Actions

## Jalanin

Butuh Python 3.12 dan Git.

Clone repo, install dependensi dari `scraper/requirements.txt`, set `PROXY_LIST`, jalanin `scraper/main.py`.

Format `PROXY_LIST` — alamat, port, username, password. Pemisah koma atau newline.

## Catatan

Struktur HTML sumber bisa berubah. Kalau parser error, cek selector-nya.

Link streaming dan download dari pihak ketiga. Kalau rusak, di luar kendali.
